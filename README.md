# BionanoAYT

Aplicación web para BionanoAYT, una empresa dedicada a la nanotecnología antimicrobiana y fungicida.

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

## Tecnologías

- React 18
- TypeScript
- Vite
- Tailwind CSS
- ShadCN UI
- React Router
